# CLAUDE.md

Context and conventions for AI assistants working in this repository.

## Repository overview

**claude-sandbox** now hosts the groundwork for a **remake of Lazarus** (Infinite Dreams, 1996, MS-DOS,
Polish). It contains reverse-engineering documentation, the original's assets converted to modern formats,
an annotated decompilation, the Python tools that produce them, and the **Godot 4 remake** (`remake/`, web
playable, widescreen, touch controls).

- **License**: MIT (Copyright 2026 mbialkowski) for code/docs; the original game (`original/`) and
  everything derived from it (`assets/`, `reference/`) belong to their rights holders and are included at
  the owner's request.
- **Primary branch**: `main`

    ├── reference_sim.py        # movement rules re-implemented; writes golden_traces.json

## Rules

- `original/` holds the unmodified original game (checksums in `original/README.md`). Never modify those
  files; only the added `README.md`, `dosbox.conf` and `CZYTAJ_utf8.txt` there are ours.
- `assets/`, `reference/lazarus.c` and `remake/data/` are generated: never hand-edit them — change the tool
  and regenerate (`python3 tools/extract_assets.py original/ assets/ --render-music`; Ghidra steps in
  `tools/ghidra/README.md`; `python3 tools/build_remake_data.py original/ remake/data/`).
  Keep `assets/README.md`, `reference/README.md` and `remake/README.md` in sync with the tools.
- The remake targets Godot 4.7 with the Compatibility renderer (web export, single-threaded). Game rules in
  `remake/scripts/sim/` must keep matching the original: run `remake/tests/golden.gd` and `scenarios.gd`
  (commands in `remake/README.md`) after changing them. GDScript: type variables explicitly when the value
  comes from an untyped object (inference from Variant is an error).
- Tools must run with Python 3.9+ and only `Pillow` + `capstone` (`tools/requirements.txt`); external
  programs are optional extras (`openmpt123`/`oggenc` for `--render-music`, `dosbox`/`Xvfb`/`xdotool` for
  `pixel_check.py`).
- When you learn something new about the game, update the relevant `docs/reverse-engineering/*.md` and,
  for code addresses, `tools/symbols.txt`.
- Addresses in docs are run-time addresses (code object at `0x10000`, data at `0x50000`).

## Workflow

- Feature branches: `claude/<description>-<session-id>`; do not push to `main` without permission.
- Push with `git push -u origin <branch-name>`.
- Commit messages: imperative mood, one logical change per commit.
