VAPID Key Generator

Generates a P-256 keypair for Web Push (RFC 8292) entirely in your browser.

Usage examples:
web-push (Node): webpush.setVapidDetails('mailto:you@example.com', PUBLIC_KEY, PRIVATE_KEY)
pywebpush (Python): webpush(subscription, data, vapid_private_key=PRIVATE_KEY, vapid_claims={"sub":"mailto:you@example.com"})

Keys are generated locally using the Web Crypto API and never leave your browser.
